## 1. Question and context

The software explores nonnegative combinations of integer generators and tries to reduce a family {ma,mb,c}, with c congruent to 1 modulo m, to a smaller two-generator problem. Global reachability claims require more than a residue calculation.




## 2. Original software claim

An earlier software generalization treated the minimal controller count for each residue as sufficient, even when further groups of m controllers create new reduced values. The error was in the Number Forge detectReduction implementation, not a claim established by the original notebook.




## 3. Evidence-supported development

Regression checks using [6,7,10] exposed the missing closure condition. The software now certifies the reduction only under a proven sufficient condition. The original Problem 3 notebook concerns the named PRISM examples, not this later software generalization.




## 4. Incorrect assumption

In residue r, the number of controllers can be r+mt, not only r. For n=ma*x+mb*y+c*(r+mt), division gives (n-r*c)/m=a*x+b*y+c*t. Ignoring t is sound only if additional c terms introduce no new reduced values. The old residue-only argument did not establish that closure.




## 5. Explicit counterexamples

For generators [6,7,10], take m=2, a=3, b=5, controller c=7. Both 14=7+7 and 21=7+7+7 are reachable. Minimal-controller reduction in residue 0 for 14 or residue 1 for 21 leaves quotient 7, which is not in the semigroup generated by 3 and 5. Thus the unqualified reduction falsely rejects both targets.




## 6. Correct sufficient condition

The minimal-controller reduction is certified here only when c is already a nonnegative combination of a and b. This condition is sufficient; a different reduction might work when it fails. Without a certificate, the app reports bounded reachability rather than a global impossibility result.




## 7. Complete conditional proof

$$
\frac{n-rc}{m}=ax+by+ct
$$

Plain text: (n - rc)/m = ax + by + ct. Write the controller count as r + mt, with 0 <= r < m and x, y, t nonnegative integers.

Let 0<=r<m and n have residue r modulo m. Because ma,mb vanish modulo m and c is 1 modulo m, every representation uses r+mt controllers for some t>=0. Therefore n is representable if and only if (n-r*c)/m belongs to S+<c>. If c belongs to S, closure gives S+<c>=S. Conversely, any quotient in S gives a representation using exactly r controllers. Negative quotients cannot represent nonnegative combinations. This proves the reduction precisely under the stated sufficient condition.

For [6,7,10], 7 is not in <3,5>, so this certificate is refused. For the named PRISM cases [9,15,25] and [9,21,49], m=3 gives reduced semigroups <3,5> and <3,7>; controllers 25 and 49 belong to them. Their certified reductions are preserved. Bounded tests separately compare 60 triples x301 targets with independent coefficient enumeration.




## 8. Consequence for software answers

14 and 21 must be reachable for [6,7,10]. Lack of this particular certificate is not evidence that a target is unreachable. No conclusion about an error in the original Problem 3 notebook follows from a defect in a later software generalization.




## 9. Reasoning lesson

A congruence class controls a count modulo m, not its full value. State a theorem with its closure assumptions and keep exact bounded calculations distinct from global certificates.




## 10. Correction history

The generalized reduction was repaired and checked against independent coefficient enumeration. This correction concerns the software; the original notebook and historical solution remain unchanged.
